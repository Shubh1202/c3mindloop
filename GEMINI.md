# Workspace Rules

## 1. Package-First Evaluation (Mandatory Rule)
When building any flow, visual component, diagram, parser, or tool:
- **Step 1**: Always check whether an established, well-maintained NPM package exists that solves the problem. If yes, use it to make the implementation cleaner and avoid reinventing the wheel.
- **Step 2**: Only write custom low-level code if no suitable, compatible NPM package exists.
